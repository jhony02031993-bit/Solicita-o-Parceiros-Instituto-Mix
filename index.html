Esta é uma ação de inclusão educacional, desenvolvida com o objetivo de ampliar o acesso à qualificação profissional e oportunidades de formação para a comunidade.

✔ Exclusivo para moradores de Flores da Cunha - RS

✔ Não se trata de golpe. Trata-se de uma ação institucional e verificada

✔ Os dados informados não são enviados para plataformas ou bancos de dados, sendo encaminhados diretamente para atendimento via WhatsApp
